How to use it

Up and running in under a minute.

  1. Install PerfDebugger from the Chrome Web Store and pin it to your toolbar.
  2. Open any page, whether it's your local dev server, staging or production.
  3. Click the ⚡ icon to see metrics stream in. Interact with the page to measure INP and re-renders.
  4. Open the dashboard (📈) to compare pages over time, or export CSV/JSON.

FAQ

Quick answers.

Is it really free?

Yes. Every feature is free, with no account, trial or paywall. It's also open source under the MIT license, so you can read every line of code on GitHub.

Why does it ask to "read and change data on all websites"?

To measure performance, PerfDebugger has to run a small script on the pages you visit. That's how Chrome describes this access. The script only reads performance data, never page content, and nothing is sent anywhere.

Does re-render detection work in production builds?

For React and Vue, yes. Component names may be minified in production, so they're most readable on a dev build. Angular needs a development build (ng serve), because production builds remove the profiling hooks.

Will it conflict with React DevTools or Vue DevTools?

No. PerfDebugger reads framework internals without installing its own DevTools hook, so the official DevTools keep working normally.

Why is the Memory metric empty?

Memory uses Chrome's performance.memory API. It's available in Chrome and most Chromium browsers, but some pages and browsers restrict it.

How do I delete my data?

Use 🗑️ Clear in the popup for a single page, or "Delete all data" in the dashboard. Uninstalling the extension also removes everything.

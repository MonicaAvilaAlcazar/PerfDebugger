PerfDebugger Privacy Policy

Last updated: October 14, 2026 · applies to version 1.0 and later

The short version PerfDebugger does not collect, transmit, sell or share any data. Everything it measures stays in your browser on your device, and you can delete it at any time.

Overview

PerfDebugger ("the extension") is a free Chrome extension that measures the web performance of the pages you visit, to help developers debug performance issues. This policy explains what the extension processes, where it is stored and how you can control it.

Data we collect

None. The developer of PerfDebugger does not collect any data. The extension has no servers or backend. It includes no analytics, telemetry, advertising or third-party SDKs, and it never sends anything over the network. The extension is open source, so you can verify this in the source code.

Data processed locally on your device

To show you performance information, the extension processes the following in your browser:

  • Performance metrics: LCP, FCP, CLS, INP, TTFB and JavaScript heap (memory) usage.
  • Page addresses: the hostname and path of pages you visit, used only to group metrics per page. The full URL of the last visit is kept so you can reopen it from the dashboard.
  • Slow network requests: the address, duration, size and type of requests slower than your configured threshold.
  • Component names: when re-render detection is on and a page uses React, Vue or Angular, the names of components that re-rendered and how many times.

The extension does not read form inputs, passwords, cookies, page text or any other page content.

Where data is stored

  • Metrics and history are stored with chrome.storage.local, on your device only.
  • Settings (thresholds, slow-request cutoff, retention period and the re-render toggle) are stored with chrome.storage.sync. If you have turned on Chrome Sync, Chrome syncs these settings between your own signed-in browsers, as it does for any extension. They contain no browsing data, and the developer has no access to them.

Data retention and deletion

  • Metrics older than your retention period (7 days by default, adjustable from 1 to 30 days in Settings) are deleted automatically.
  • You can delete one page's data with Clear in the popup, or everything with Delete all data in the dashboard.
  • Uninstalling the extension removes all of its stored data.

Exports

The JSON and CSV export buttons create a file that your browser saves to your device. Nothing is uploaded. You decide whether and where to share these files.

Permissions explained

PermissionWhy it's needed
storageSave metrics and history locally, and save your settings.
alarmsRun an hourly cleanup that deletes data older than your retention period.
Host access to all sitesRun the measurement script on the pages you visit, and show the current page's address in the popup. The script only reads performance data.

Third parties

PerfDebugger does not share data with anyone, and it doesn't use third-party analytics, tracking, advertising or remote code. All code is packaged inside the extension.

Chrome Web Store User Data Policy

The use of information processed by PerfDebugger complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide the extension's single purpose, measuring and displaying web performance, and is never transferred, sold or used for advertising, creditworthiness or any unrelated purpose.

Children's privacy

PerfDebugger is a developer tool. It is not directed at children and collects no personal information from anyone.

Changes to this policy

If this policy changes, the updated version will be published on this page with a new "Last updated" date. Any change that affects how data is handled will also be noted in the extension's release notes.
